# 디자인 시안 노트

주제: 마인크래프트 플러그인 / 서버 개발자의 포트폴리오.
보는 사람: 서버 운영자(플러그인 의뢰), 게임 회사 백엔드 채용 담당, 오픈소스 사용자.
페이지의 일: "이 사람이 만든 서버는 사람이 몰려도 버틴다"를 숫자와 구조로 보여 주기.

**마크틱하지 않게** (사용자 요청): 픽셀 폰트, 블록·잔디·흙 텍스처, 초록-갈색 팔레트,
아이템/인벤토리 UI 흉내, 게임 메뉴 버튼 모양 금지. 대신 서버 개발의 언어
(틱 예산 50ms, 네트워크 구조, 버전과 변경 내역)에서 시각 요소를 가져온다.

피한 기본값: 크림 + 테라코타, 검정 + 형광 단색, 신문식 헤어라인, 똑같은 둥근 카드,
대문자 eyebrow / 가운뎃점 메타 / 화살표 링크.

1차 시안(Playfield, Level Select, Sprite Sheet)은 게임·크리에이티브 코딩 전제였고
픽셀 요소가 마크를 떠올리게 해 폐기.

## A. Tick — 50ms 예산
- 대담함: 히어로의 실시간 틱 그래프. 1초에 20칸, 각 막대 높이 = 그 틱의 처리 시간, 50ms 예산선.
- 색: paper #F4F6F8, graphite #1F2328, slate #5B6472, indigo #3A3FD9(막대), rule #DDE1E7, alert #C2185B(예산선만)
- 서체: Instrument Sans(제목·숫자, 좁은 폭), Pretendard(한글 본문)
- 작업 목록은 측정값이 있는 표(이름 | 하는 일 | 대표 수치).

## B. Topology — 네트워크 구조도
- 대담함: 클라이언트 → Paper/Rust 서버 → 서버 내부 → 게임 플러그인 → 웹·운영 도구 구조도. 작업을 고르면 그 작업이 맡은 층이 켜진다. (실제 작업 기준으로 다시 그림)
- 색: haze #E6EBEF, ink #0E1A24, node #FFFFFF, wire #8A99A6, amber #F2A900(켜진 경로)
- 서체: Geist 하나(+ 한글 Pretendard)

## C. Release Notes — 버전이 곧 이력
- 대담함: 거대한 버전 숫자. 작업마다 한 릴리스, 변경 내역은 추가 / 수정 / 성능 기호로 분류.
- 색: deep teal #0F4C5C 바탕, bone #F1ECE2 글자, mist #A9C3C9, amber #FFB547(성능 표시만)
- 서체: Big Shoulders Display(버전 숫자), Pretendard(본문)
